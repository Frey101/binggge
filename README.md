# binggge

Une application minimale de suivi de séries : chercher une série, l'ajouter à sa liste, cocher les épisodes vus.

## Démarrage rapide

```bash
cd api && npm install
npm start
````

**Note sur l'authentification :** Pas d'authentification réelle, l'en-tête `X-User` tient lieu d'identité.
